# Android Level 1 - Task 1 - Unit Converter

## 📱 Project Overview

This project is an Android Unit Converter application developed as part of the Oasis Infobyte Android App Development Internship.

The application allows users to convert values between different units of measurement based on the selected category.

## 🎯 Objective

To build a simple Android application that converts values between common units such as length, weight, and temperature.

## 🛠️ Technologies Used

- Android Studio
- Java
- XML
- Android SDK

## ✨ Features

- Numeric input field
- Source unit selection
- Target unit selection
- Convert button
- Displays converted result with unit
- Supports multiple measurement categories
- Input validation
- Toast message for empty or invalid input
- Category selector for switching between measurement types

## 📏 Supported Categories

- Length
- Weight
- Temperature

## ▶️ How to Use

1. Enter a numeric value.
2. Select the measurement category.
3. Select the source unit.
4. Select the target unit.
5. Tap the Convert button.
6. The converted value is displayed on the screen.
